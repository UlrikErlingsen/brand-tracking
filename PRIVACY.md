# Privacy

TrackSignal does not implement telemetry, advertising, user accounts, tracking pixels, or outbound data uploads. Files are processed by the running Streamlit application. If someone deploys the app, that operator controls infrastructure logs, retention, authentication, backups, and network access and must document those practices separately.

Do not upload personal or confidential respondent data to a deployment you do not control. Prefer de-identified respondent IDs and apply appropriate access, retention, and disclosure controls.
